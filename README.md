# Meldix Chat Archive — Revenge Classic

Плагин для локального экспорта **одного личного DM-чата** в Discord: сообщения обоих участников, даты, ответы, реакции и метаданные вложений. Дополнительно формирует `site-notes.md` с темами и подтверждающими цитатами для подготовки личного сайта.

## Установка на Android

В **Revenge Classic → Settings → Plugins → +** вставь URL **каталога плагина**:

```text
https://cdn.jsdelivr.net/gh/Meldixx/Meldix-Chat-Archive@main/
```

Revenge сам запрашивает из этого каталога `manifest.json` и `index.js`. Ссылка на `raw.githubusercontent.com/.../main/` **не работает**: GitHub RAW не раздаёт папку как сайт.

Если владелец репозитория включит **Settings → Pages → Deploy from a branch → main / (root)**, можно использовать также:

```text
https://meldixx.github.io/Meldix-Chat-Archive/
```

GitHub Pages не включён и не проверен автоматически; эта ссылка будет работать только после публикации.

## Экспорт

1. Открой личный чат с нужным человеком.
2. Скопируй ссылку на сообщение вида `https://discord.com/channels/@me/DM_ID/MESSAGE_ID` или узнай ID **канала DM** (не ID пользователя).
3. В настройках Meldix Chat Archive вставь ссылку или DM ID и нажми «Собрать доступную историю».
4. Файлы сохраняются локально в Documents приложения: `messages-0001.json`, следующие части, `index.json`, `site-notes.md`.
5. Если нужно, останови выгрузку. Индекс пометит её как неполную.

Необходимая версия: **Revenge Classic**, Vendetta-подобный формат. Для Revenge Next ZIP-плагин другого типа не подходит.

## Приватность и точность

- Никакой переписки на GitHub, внешние вебхуки или сторонние серверы не отправляется.
- HTTP-запросы идут только к Discord через клиент. Плагин не извлекает токен аккаунта.
- Содержимое вложений не скачивается; сохраняются лишь метаданные.
- Удалённые/недоступные сообщения не восстанавливаются.
- Выводы о чувствах человека **не делаются**. Тематические совпадения не доказывают значимость события.
- Не выкладывай в репозиторий экспортированные переписки, личные данные и цитаты без согласия другой стороны.

Версия **1.0.3** исправляет рендер экрана настроек в Revenge Classic: в поле `settings` передаётся компонент `Settings`, а не уже созданный React-элемент. Также обновлён `hash` в манифесте. Если CDN отдаёт старую версию, установи релиз по адресу с SHA коммита, указанному в ответе. Реальную установку в конкретной сборке Revenge Android ещё нужно проверить.
