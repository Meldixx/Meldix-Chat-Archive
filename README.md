# Meldix Chat Archive — Revenge Classic

**v1.0.7** — экспортирует доступную историю одного личного DM **в один обычный `.txt` файл** и открывает системное окно Android **«Сохранить как…»**. Выбери там **Загрузки / Downloads** и нажми «Сохранить». Никаких JSON-частей, отдельных индексов и отчётов.

## Установка

Revenge Classic → Settings → Plugins → +:

```text
https://cdn.jsdelivr.net/gh/Meldixx/Meldix-Chat-Archive@main/
```

Для гарантированной загрузки новой версии без старого CDN-кэша удали предыдущий плагин и установи ссылку с SHA нового коммита из сообщения о выпуске.

## Как сохранить файл в «Загрузки»

1. Открой нужный личный чат, скопируй ссылку на сообщение вида `https://discord.com/channels/@me/DM_ID/MESSAGE_ID`.
2. В настройках плагина вставь ссылку или **ID DM-канала** (не ID пользователя).
3. Нажми **«Собрать чат и сохранить в Загрузки»**.
4. Когда чат загрузится, Android откроет системный выбор места сохранения. Перейди в **Загрузки / Downloads**, оставь предложенное имя файла `chat-DM_ID-время.txt` и нажми **«Сохранить»**.
5. Открой штатное приложение «Файлы» → «Загрузки» и найди TXT.

**Важно:** Android требует подтвердить сохранение в общую папку через системное окно. Плагин не может принудительно выбрать «Загрузки» вместо тебя. Он не притворяется, что файл уже там, пока Android не вернул результат сохранения.

Если закрыть окно «Сохранить», временный TXT останется в **закрытом кеш-каталоге приложения**, и можно повторить попытку кнопкой **«Сохранить в Загрузки»** без повторной загрузки всей переписки. После удачного экспорта временный файл удаляется.

## Формат

```text
[2026-09-22 02:15:00 UTC] Ваня: Привет!

[2026-09-22 02:16:00 UTC] Ксюша: Мяу мяу мяу мяу
```

TXT сохраняется как **UTF‑8 с BOM**: это позволяет Chrome и другим Android-просмотрщикам правильно отображать русский текст вместо «кракозябр». Файл можно также открыть в любом редакторе с поддержкой UTF‑8.

Сообщения идут от старых к новым; сохраняются дата и время UTC, автор, текст и названия вложений/стикеров. Содержимое вложений не загружается. Удалённые или недоступные сообщения восстановить нельзя. При досрочной остановке сохраняется только доступная к тому моменту часть.

## Совместимость и приватность

Для публичной папки используется системный `saveDocuments` из `@react-native-documents/picker`. Если этот модуль отсутствует в конкретной версии Discord, плагин выдаст понятную ошибку **до** загрузки длинного чата, а не оставит пользователя с недоступным внутренним файлом. Плагин рассчитан на Revenge Classic / Vendetta, а не Revenge Next.

Переписка не отправляется на GitHub или сторонние серверы. Сохранённый в Downloads TXT доступен через обычный файловый менеджер и приложения с разрешением читать этот файл: не публикуй личную переписку без согласия второго участника.

В коде проверен путь сохранения с эмуляцией Android picker; реальную работу системного окна на твоём телефоне необходимо проверить.
