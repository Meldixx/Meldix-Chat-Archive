# Meldix Chat Archive — Revenge Classic

**v1.0.4** — сохраняет доступную историю выбранного личного DM **в один обычный `.txt` файл**. Никаких JSON-частей, `index.json`, отчётов или AI-анализа.

## Установка

Revenge Classic → Settings → Plugins → +:

```text
https://cdn.jsdelivr.net/gh/Meldixx/Meldix-Chat-Archive@main/
```

Если CDN показывает старый код, удали предыдущую установку и вставь ссылку на конкретный коммит новой версии из сообщения о выпуске.

## Использование

1. Открой нужный личный чат Discord, скопируй ссылку на сообщение вида `https://discord.com/channels/@me/DM_ID/MESSAGE_ID`.
2. В настройках плагина вставь ссылку или **ID DM-канала**, не ID пользователя.
3. Нажми **«Собрать чат в TXT»** и дождись завершения или останови, чтобы сохранить уже полученное.
4. В Documents приложения появится только **`chat-DM_ID-время.txt`**. Нажми **«Поделиться одним TXT»**, чтобы попробовать открыть системную отправку файла.

Формат строк:

```text
[2026-09-22 02:15:00 UTC] Ваня: Привет!
 
[2026-09-22 02:16:00 UTC] Ксюша: Мяу мяу мяу мяу
```

Сообщения идут от старых к новым, с датой и временем UTC, автором и текстом. Для сообщений с вложениями или стикерами сохраняются только их названия — содержимое файлов не скачивается.

Экспорт не восстанавливает удалённые или недоступные сообщения. Если процесс прерван или Discord вернул ошибку, плагин укажет **неполный экспорт** на экране, а один TXT сохранит то, что успело загрузиться.

## Приватность

Плагин читает только указанный личный DM через внутренний клиент Discord и сохраняет TXT локально. Не загружай приватный чат в публичный репозиторий. Для большого файла системное Android-меню отправки может быть недоступно в отдельных сборках; плагин покажет путь к TXT в Documents приложения.

Revenge Classic / Vendetta; не Revenge Next. Реальный запуск и отправку файла именно на твоём телефоне нужно проверить.
